# Acc Cell WebApp — Link Bio Interaktif & Katalog Smartphone

Link bio resmi Acc Cell (Nabire & Serui): katalog HP baru, second, dan aksesoris bergaya premium; rekening & QRIS resmi; servis dan tukar tambah; chat langsung ke WhatsApp admin cabang; plus dasbor admin (superadmin + admin cabang), notifikasi WhatsApp/Email, CRM kontak, migrasi data, dan PWA.

- **Frontend:** HTML/CSS/JS vanilla (SPA, router hash, cache perangkat → pindah halaman instan).
- **Backend:** Google Apps Script (REST API JSON) + Google Sheets + Google Drive.
- **Konfigurasi:** `js/config.js` (isi `GAS_URL`). Kosong = mode demo dengan data contoh.
